# Research data

This directory is for human-readable, non-proprietary research tables.

Suggested files:

- `archive_entries.csv` — known PAK entries and purposes;
- `runtime_addresses.csv` — verified RAM/VRAM/code addresses;
- `message_inventory.csv` — string-bank progress without dumping original text;
- `function_map.csv` — function names, overlays, evidence, and confidence;
- `localization_progress.csv` — screen/content completion status.

Never add raw ROM, RAM, VRAM, save-state, or extracted archive dumps.
