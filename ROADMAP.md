# Roadmap

## Localization

- Inventory every remaining dynamic Japanese string.
- Finish all menu-tutorial frozen frames using native captures and in-place
  tile edits.
- Audit story, battle, formation, items, Digimon data, system prompts, and
  post-game content.
- Standardize terminology and proofreading.

## Runtime and formats

- Complete Xros PAK archive documentation.
- Map NitroFS graphics archives to runtime VRAM destinations.
- Document ARM9 BLZ compression metadata and the compressed-end pointer.
- Identify every runtime font/message renderer and control code.
- Automate containment and emulator smoke tests.

## Decompilation

- Produce a function/overlay map with evidence and confidence.
- Recover high-level structures for menus, messages, battle state, save data,
  and asset loading.
- Add symbol files and pseudocode notes without distributing original binaries.
- Progress toward independently buildable replacement components where lawful.

## Community release engineering

- Publish a legal binary patch for v145.
- Add Windows, macOS, and Linux patch instructions.
- Add CI for Python tests, forbidden-file checks, and documentation links.
- Maintain a public untranslated-content tracker.
