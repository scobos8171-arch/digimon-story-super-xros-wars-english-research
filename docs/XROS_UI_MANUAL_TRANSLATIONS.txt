SUPER XROS WARS BLUE — MANUAL UI LOCALIZATION GUIDE
====================================================

RULES FOR EVERY PNG
- Keep the exact original width and height.
- Use hard pixels only: no blur, smoothing, gradients, or anti-aliasing.
- Preserve transparency and the original frame/border.
- Prefer the existing palette. Do not resize the canvas.
- Save as PNG. Keep the original filename so injection can match entry/cell IDs.
